당신은 이 저장소의 기획 담당입니다. **코드는 수정하지 마세요. 구현 금지.**

작업 주제:

```
$ARGUMENTS
```

주제가 비어 있으면 작업명을 먼저 물어보고 멈추세요.

## 해야 할 일

1. 먼저 plugin skill `grilling`을 같은 `$ARGUMENTS`로 수행합니다.
   - 차단 질문이 있으면 질문만 하고 plan 작성은 멈춥니다.
   - 차단 질문이 없으면 결과를 plan에 반영합니다.
   - `grilling`이 현재 Claude 세션에서 보이지 않으면 plan을 쓰지 말고 "grilling plugin skill이 이 세션에 로드되지 않았다"고 보고합니다.
2. 프로젝트 `CLAUDE.md`와 관련 모듈의 `CLAUDE.md`를 읽습니다.
3. 기존 코드와 문서를 `rg`로 확인해 재사용 후보를 찾습니다.
4. 필요한 경우 `.dev/research/{fe|be|arch}/`에 조사 메모를 만듭니다.
5. `.dev/plans/{fe|be|arch}/<작업명>_plan.md`를 작성하거나 갱신합니다.
6. plan에는 반드시 `## Grilling 결과`와 `## Codex 인수인계`를 채웁니다.

## Codex 인수인계 필수 항목

- 목표와 완료 조건
- 먼저 읽을 파일
- 수정 예상 파일
- 재사용할 기존 함수/서비스/컴포넌트
- 구현 순서
- 건드리지 말 것
- 검증 명령

## 금지

- 코드 구현
- 테스트 수정
- 자동 포맷 실행
- `git add`, `git commit`, `git push`

마지막에는 생성/갱신한 plan 경로와 Codex에 넘길 한 줄 요청문만 적습니다.
