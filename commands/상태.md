당신은 상태 확인 담당입니다. **코드 수정 금지.**

확인할 run id 또는 plan:

```
$ARGUMENTS
```

## 절차

1. `.\ai.ps1 status`를 실행합니다.
2. `.\ai.ps1 tasks`를 실행합니다.
3. 인자가 있으면 해당 로그를 봅니다.

```powershell
.\ai.ps1 tail $ARGUMENTS
```

4. 인자가 없으면 최신 run이 `running`인지, `completed`인지, `failed`인지 간단히 말합니다.

## 출력

- 현재 실행 중인지
- 마지막 run id
- 실패면 마지막 에러 5줄
- 다음 명령 하나
